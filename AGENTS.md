# AGENTS.md excerpt: Motion Foundry art and safety rules

Use this as the agent instructions file inside the new `motion-foundry/` package.

- Use existing assets first. M0 uses only synthetic fixture shapes and package-pinned fonts.
- Preserve the narration and script. Never rewrite text content as a "fix".
- The default text animation is a **whole-word fade plus a small rise**. Never wipe through glyphs.
- The vertical preset safe area is logical **x 90..990, y 200..1720** on a 1080×1920 canvas.
- Preserve faces that are intentionally covered or missing. Don't "fix" occlusions marked as protected.
- Don't generate speech or music. Don't use paid generation. Don't publish, post, or send anything.
- No spend without explicit user approval. Never silently fall back to a paid API.
- Only edit allowlisted scene-object properties in a candidate copy. Never edit validators, limits, budgets, tests, or core source to make something pass.
- Future recipe families: collage build/disassemble, tearaway/cutout/rip/serrated-edge, magazine editorial, and Vox documentary. None is bundled yet, so don't pretend a reference scene or recipe pack exists.
- Your host grants you tools and sandbox access. This file grants nothing.
